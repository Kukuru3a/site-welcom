# Универсальный сайт частного мастера — WordPress + Docker

## Основной вариант: WordPress

Тема находится в `wp-content/themes/master-template`. Развёртывание — в `docker-compose.yml`: WordPress 6.7, PHP 8.2 и MariaDB 11.4. В панели WordPress → **Сайт мастера → Профиль и настройки** меняются фото мастера, логотипы и иконки, тексты разделов, контакты, цвета, оценка и количество отзывов в плашке Авито. Фото мастера показывается на первом экране и в разделе «Обо мне». В подразделах **Услуги**, **Работы** и **Вопросы** можно добавлять, изменять, удалять и снимать с публикации записи. Фото работ выбираются из медиатеки в редакторе работы. Раздел отзывов на публичной странице удалён.

1. Скопируйте `.env.example` в `.env`, задайте надёжные `DB_PASSWORD` и `DB_ROOT_PASSWORD`.
2. Запустите `docker compose up -d` в этой папке.
3. Откройте `http://localhost:8000`, завершите стандартную установку WordPress и активируйте тему **Универсальный сайт мастера** в разделе «Внешний вид → Темы».
4. В «Сайт мастера → Профиль и настройки» замените данные и фото мастера; в подразделах услуг, работ и вопросов обновите содержимое. Для плашки Авито укажите подтверждённые оценку и количество отзывов.

Исходный логотип темы — `wp-content/themes/master-template/assets/electrician-logo.jpg`; его можно заменить через медиатеку. Девять услуг добавлены как **примеры цен**: подтвердите суммы и снимите отметку «Пример цены» в каждой услуге перед публикацией реальных расценок. Четыре карточки работ используют иллюстрации-заготовки и редактируются в разделе «Работы». Замените их своими фотографиями и текстами, затем снимите отметку «Заготовка».

Ссылки на Telegram, ВКонтакте и Авито задаются в отдельном разделе **Сайт мастера → Ссылки соцсетей**. Введите полные HTTPS-адреса и нажмите кнопку **«Сохранить ссылки»** сразу под полями. Пустое поле оставляет иконку без перехода. После сохранения ссылки на нужный сервис иконка становится кликабельной.

Для Telegram задайте `LEAD_CHANNEL=telegram`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` в `.env`. Для ВКонтакте задайте `LEAD_CHANNEL=vk`, `VK_GROUP_TOKEN`, `VK_PEER_ID`. После изменения `.env` выполните `docker compose up -d`. Токены остаются в серверном окружении.

Заявки сохраняются как закрытые записи WordPress в разделе «Сайт мастера → Заявки мастера». Ответ формы подтверждает сохранение в базе. Отправка уведомления происходит сразу, а неудачные попытки повторяются через WP-Cron раз в пять минут (WP-Cron запускается при посещениях сайта). Для регулярной доставки на малопосещаемом сайте настройте системный cron на вызов `wp-cron.php`; следите за заявками со статусом `pending` и делайте резервные копии базы. Без настроенного канала заявки сохраняются, уведомления не отправляются.
